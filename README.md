# Misión Especial de Meme

Este paquete está preparado para publicarse gratis con GitHub Pages.

## Cómo publicarlo

1. Ingresá a https://github.com/new
2. En **Repository name**, escribí exactamente: `MisionEspecialdeMeme`
3. Elegí **Public** y presioná **Create repository**.
4. Dentro del repositorio, seleccioná **uploading an existing file** o **Add file → Upload files**.
5. Descomprimí el ZIP y subí estos archivos directamente a la raíz del repositorio:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `.nojekyll`
   - `README.md`
6. Presioná **Commit changes**.
7. Entrá en **Settings → Pages**.
8. En **Build and deployment**, seleccioná **Deploy from a branch**.
9. Elegí la rama **main**, la carpeta **/(root)** y presioná **Save**.

La dirección final será:

https://memeriego.github.io/MisionEspecialdeMeme/

GitHub puede tardar algunos minutos en activar la página. El formulario de la cita seguirá enviando la notificación mediante Formspree.
